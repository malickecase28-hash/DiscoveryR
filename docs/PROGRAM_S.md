# Program S — Strategy / Alpha Research

Program S begins only with confirmed behavioral information from R. A confirmed
detector relationship is an input, not a confirmed strategy.

The declared artifact is a `StrategyHypothesis` plus explicit decision rules for
entry, exit, sizing, and management. It also names execution assumptions, a cost
model, risk rules, and causal walk-forward partitions. Supported archetype
labels are continuation, exhaustion/reversal, structural reaction, breakout,
mean reversion, multi-scale structural, regime filter, and
execution/abstention; labels do not hardcode a strategy.

The descriptive runner produces a `StrategyValidation` containing input
identities, timing, coverage, abstentions, costs, risks, and validation
evidence. The strict causal simulation path attaches input IDs per observation;
the bound confirmation API requires all declared challenge attacks and a
custodian receipt. Method challenge
attacks lookahead, selection, controls, temporal dependence, multiple testing,
fragility, concentration, and alternative explanations. Challenge survival and
promotion are evidence states, not confirmation.

Detector confirmation data are contaminated once their outcomes influence
strategy construction. The holdout policy must therefore reserve a nested
strategy holdout or future-data scope before exposure. Strategy confirmation
freezes claim, population, anchor, context, outcome, metric, code, controls,
null, and multiplicity family and requires an external custodian. Synthetic
confirmation labels are test fixtures only.

No live order, broker, fill, or capital authority belongs to Program S.
